# C-钱包份额

> 来源：[[思维导图：下半场，我们要靠本事赚钱了#🎯 钱包份额：卖给客户更多]]
> 原文：[[03_Resources/02_商业化与创业/inbox/下半场，我们要靠本事赚钱了/下半场，我们要靠本事赚钱了]]

## 定义
不要看自己在行业的份额，要看在客户总消费中的份额。提供更多品类/场景，让客户在你这里消费更多。

## 核心逻辑
- 可口可乐案例：从软饮市场 → 人类胃的需求
- 客户每年花1万在食品上，你在其中只占500 → 争取更多份额
- 通过更多品类/场景，让客户在你这里消费更多

## 关键洞察
- 竞争对手不只是同行，而是所有争夺客户钱包的品牌
- 火锅的竞争对手不是其他火锅，而是所有正餐
- 一个人吃火锅 → 夜市小份菜 → 新场景新需求

## 可复用场景
- 产品策略：围绕客户需求扩展品类
- 场景拓展：为现有产品找到新的使用场景
- 客户深耕：了解客户总消费结构，找到增长空间
